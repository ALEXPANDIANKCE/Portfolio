# Alexpandian A — Next.js Portfolio

A professional responsive portfolio built with Next.js, TypeScript, Tailwind CSS and Framer Motion.

## 1. Requirements

Install:
- Node.js 20+
- VS Code
- Git

Check Node:
```bash
node -v
npm -v
```

## 2. Install

```bash
npm install
```

## 3. Run locally

```bash
npm run dev
```

Open:
http://localhost:3000

## 4. Add your real resume

Replace:
`public/Alexpandian-Resume.pdf`

with your actual PDF resume using the same filename.

## 5. Update links

Open `app/page.tsx` and replace:
- GitHub URL
- LinkedIn URL
- Project GitHub/demo URLs if you add them

## 6. Build for production

```bash
npm run build
npm start
```

## 7. Deploy on Vercel

1. Create a GitHub repository.
2. Push this project.
3. Go to Vercel.
4. Import the GitHub repository.
5. Keep the default Next.js settings.
6. Click Deploy.

## Notes

The contact form currently demonstrates a successful local submission. For real email delivery, connect the form to an email provider or backend endpoint.
